# ADR-0003：开源复用优先与自研冒烟门禁

- 状态：Gate 1 待确认
- 日期：2026-08-23

## 背景

汐灵横跨 Chat、画布、项目、Wiki、图分析、科学计算和跨平台运行。重复实现成熟基础设施会提高缺陷率和长期维护成本。

## 决策

新能力必须先完成开源评估，依次选择直接依赖、协议兼容、设计参考，最后才允许自研。自研项必须具备 ADR、稳定接口、替换边界和离线 smoke 测试。

## 许可证政策

- MIT、BSD、Apache-2.0 优先。
- MPL、LGPL、EUPL 逐项确认组合与分发义务。
- AGPL、SSPL、自定义许可证默认不进入核心代码。
- 直接和传递依赖均进入 SBOM、第三方声明和 CI 扫描。

## 结果

- Gate 2 起每个自研模块没有 smoke 测试不得合并。
- 依赖升级必须通过契约测试。
- 热门程度不能覆盖许可、安全、体积和适配成本判断。
