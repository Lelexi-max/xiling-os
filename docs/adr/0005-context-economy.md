# ADR-0005：以机制实现上下文经济，而非固定 Token 限额

- 状态：Gate 1 待确认
- 日期：2026-08-23

## 背景

固定冷启动、检索和工具 token 上限虽然便于测量，但会把成本控制变成任意裁剪，可能损害长文献链和复杂科研任务的证据完整性。

## 决策

采用活动分支投影、显式 Quote、增量 Context Capsule、内容寻址 Artifact、两阶段检索、任务包隔离、能力发现和稳定前缀缓存。Token 统计用于观测、成本预测和异常保护，不作为正常研究任务的统一硬限制。

## 结果

- 无关分支、Skill、MCP 和大 payload 天然不进入模型请求。
- 旧内容可通过可追溯胶囊复用，精确原文仍可按 ID 读取。
- 超出模型窗口时按语义降级并向用户说明，不静默删除证据。
- 测试重点从“必须小于某个数字”转为重复率、缓存率、证据密度和投影正确性。
